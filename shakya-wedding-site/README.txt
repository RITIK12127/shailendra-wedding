दीपावली ♥ शैलेन्द्र — Wedding Invitation Website

चलाने का तरीका:
1. इस folder को डाउनलोड करें।
2. index.html को ब्राउज़र में खोलें या VS Code में Live Server चलाएँ।
3. वेबसाइट Google Fonts के लिए इंटरनेट का उपयोग करती है; बाकी साइट लोकल चलती है।

बदलाव:
- नाम, तारीख और कार्यक्रम: index.html
- रंग, लेआउट और मोबाइल डिजाइन: style.css
- Opening, falling petals और scratch card: script.js

नोट:
- वेबसाइट में कोई कपल फोटो नहीं रखी गई है।
- कार्यक्रमों की जानकारी दिए गए शादी कार्ड के अनुसार रखी गई है।
- मैप बटन फिलहाल Ganpati Vihar Colony, Vidisha की Google Maps खोज खोलता है; सटीक विवाह-स्थल पिन मिलने पर इसे अपडेट किया जा सकता है।
